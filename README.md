# 💐 digital-bouquet

A digital birthday bouquet — a single-page surprise website with a teasing gift box,
a hand-drawn blooming flower animation, twinkling stars, drifting petals, and a
personal birthday message. No frameworks, no build step: one `index.html`.

**How it works:** the page opens on a bouncing 🎁 whose button playfully dodges the
cursor (or taps, on a phone) three times before it lets itself be clicked — then the
bouquet blooms flower by flower and the birthday message appears.

## Use this template

1. Click **Use this template** on GitHub to create your own copy.
2. Open `index.html` and personalize it:
   - Replace `[Name]` and `[Full Name]` in the block marked `✏️ EDIT YOUR MESSAGE HERE`.
   - Optionally tweak the message text, the `<title>`, and the intro line
     ("Pssst… there's a surprise for you").
3. Enable GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.
4. Share your link: `https://<your-username>.github.io/<your-repo>/` 🌸
